# Bot Poltronix

Posta automaticamente capa, título (ano) e sinopse de filmes no canal [@poltronix](https://t.me/poltronix), com o botão "🎬 ASSISTA AQUI" levando para [@canalpoltronix](https://t.me/canalpoltronix). Dados e imagens: [TMDB](https://www.themoviedb.org/).

- **Automático:** 1 lançamento em cartaz às 12h, 18h e 22h (Brasília).
- **Sob pedido:** mande `/postar Nome do Filme` no privado do bot (confere a cada 10 min).
- **Pelo GitHub:** Actions → Bot Poltronix → Run workflow → nome do filme.

Secrets necessários (Settings → Secrets and variables → Actions): `TELEGRAM_TOKEN`, `TMDB_TOKEN`, `ADMIN_USERNAME`.
